# Steam Market Listings Group

在 Steam 市场商品详情页的原版“出售 - 我的上架物品”列表上增加聚合与批量操作。当前版本 **3.0.2**，使用原版容器、商品图文和 Steam 深色样式。

## 显示模式

| 模式 | 每行内容 | 勾选范围 |
| --- | --- | --- |
| 按价格 | 跨日期合并相同买方价格，显示日期范围和数量 | 该价格的全部挂单 |
| 按日期 | 同一天、同一买方价格一行；同日不同价格分别成行 | 该日期与价格的全部挂单 |
| 原版 | 保留 Steam 实际列表节点，每件物品一行 | 单件挂单 |

默认按价格显示，切换模式会保存偏好。已选物品在三种模式间保留；聚合行支持半选状态。顶部“全选”选择当前商品的全部已提取挂单。

## 操作

1. 勾选单件或聚合行，点击“下架选中”或“重新上架选中”。
2. 点击第一行最右侧的“全部下架”或“全部重新上架”，处理全部挂单，忽略勾选状态。
3. 聚合行直接点击“下架 / 重新上架”处理整组；原版行点击“修改”后选择操作。
4. 重新上架时填写“您将收到”或“买方支付”，查看总到手金额后确认。所有操作都有确认步骤，批量执行期间禁止重复启动。

下架成功后列表自动更新。重新上架会等待物品回库并获取新的资产 ID，成功后更新挂单 ID、日期和价格。上架失败的物品从挂单列表移除，并提示已回到库存；需要手机/邮件确认或响应不明确时提示“待核实/确认”，请在 Steam 完成确认并刷新核对。

## 安装或更新

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 安装 [脚本](https://github.com/rayroad/steamMarketListingsGroup/raw/master/steam-market-listings-group.user.js)，或将本地 `steam-market-listings-group.user.js` 全部内容粘贴到已有脚本编辑器并保存。
3. 确认 Tampermonkey 中版本为 **3.0.2**，刷新 Steam 市场商品详情页。

默认有 1 件挂单即可显示。可通过 Tampermonkey 菜单调整“最少检测上架数量阈值”；已有保存值会继续生效。

## 技术与验证

运行时为单文件 IIFE，无构建步骤和外部依赖；从 `unsafeWindow.SSR.loaderData` 提取当前账号挂单。交易使用 Steam 登录会话；会话缺失时读取其他 Steam 页面作为回退。

已依据 2026-11-26 的 Steam 新版挂单 DOM 实现。原版行不提供挂单 ID，因此按初始日期、价格和出现顺序匹配 SSR 数据；无法匹配的行不会绑定脚本交易操作。Steam 页面重绘后自动恢复增强面板和选择状态。

开发验证使用 Node.js 24+ 和仅供测试的 jsdom：

```sh
npm ci
npm run check
npm test
```

12 项离线测试覆盖模式、选择、重绘、取消与互斥、交易请求及成功/失败状态同步。已在浏览器检查模拟页面；真实下架/上架需安装后用少量挂单验证。
